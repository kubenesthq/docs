Kubenest Backend API for managing Kubernetes clusters, projects, workloads, and addons.

This API provides a centralized control plane for deploying and managing applications
across multiple Kubernetes clusters with GitOps-style workflows.

## Features
- Multi-cluster management
- Project-based namespace isolation
- Workload deployment with multiple build modes (image, dockerfile, buildpack)
- Addon management (databases, message queues, etc.)
- Real-time event streaming via Server-Sent Events
